What the other pages do

Extraction Desk is the main four-in-one source ingestion/checkpoint workspace. Daily Progress contains the limited historical approved Project Work reports (not live engineering completion). Sources & History is an audit page for source ownership, dates and edit links. Field staff should ordinarily start with the Project Map and project notifications.

Operations quick start

  1. Choose a site in the Notification Center or Project Map using its stable project ID.
  2. Choose a site on the Project Map to reveal its reviewed notifications below the map, then open the separate Daily Progress page for reported work. A notice is not automatically outstanding.
  3. Correct facts in the owning Google Sheet. Use the repository for code, tests and publication history.
  4. Check the next Actions run, the separate Sources & History page, and the live site. Open documents through the Resource Library, where Drive controls access.
