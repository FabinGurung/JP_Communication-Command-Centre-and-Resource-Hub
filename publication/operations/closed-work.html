How to close or remove a task from the active view
  1. Locate its stable Notification ID or Project Work ID in the original owning Google Sheet. Do not delete or move the original row.
  2. Record Closure Decision as COMPLETED, NOT_REQUIRED, CANCELLED, or SUPERSEDED. A reason, date and reviewer are required. Completion also requires an evidence reference and verified work status; supersession requires the replacement ID.
  3. After source review, set Closure Approved = TRUE. An unapproved or incomplete decision stays visible in the active source view. Only an approved closure moves here after the next successful Actions publication.
  4. To correct or reopen a closure, preserve an audit receipt and source revision; do not silently erase the earlier decision. Keep original evidence restricted.

The existing workbooks currently have no recorded, approved closure fields. Their owners must add the documented closure columns under A7 PRE/POST source version control before closing real rows. This public GitHub Pages website is deliberately read-only.
