## Genuine limitations and future work (not release blockers)

- This is a static GitHub Pages frontend with versioned JSON/CSV/SQL *contracts*, not a running PostgreSQL service.
- The personal daily checklist remains browser-local; it is not team-synchronized.
- Fully authenticated private Drive metadata pagination, GitHub-to-Google Sheets projections and Control Tower synchronization remain future platform integrations.
- The Discord collector remains **ON HOLD**. This milestone does not resume collection or assert that outstanding media mismatches were resolved.
- Project engineer signatures and drawing issue states remain project **Progress** records, not website release blockers.
- Botanical aesthetics and responsive layouts were browser-tested at the documented widths; actual device-specific appearance may still vary slightly across OS/browser combinations.
