# v2.8.0 — Notification-first hybrid pages and site-specific Notification Center

**Release date:** 13 November 2026 (Nepal time). **Repository:** `FabinGurung/jp-site-operations`.

## New information architecture
The previous home page stacked Notifications, Map, Daily Progress and Sources. Users could only scroll within that one long document. The new hybrid navigation makes home contain **Notification Center first, Project Map second**. Each of **Daily Progress** (`/progress.html`) and **Sources & History** (`/sources.html`) has an actual independent HTML page under the same Pages origin. Owner Guide and the independent Field & Desk Resource Library links remain available. Historical `#progress`, `#sources` and `site-operations/history.html` URLs continue to reach the correct internal pages.

## Notification desk
A large source-safe Notification Center panel shows reviewed instruction cards with:
- Site dropdown synchronized with existing directory/project selector and map pins
- Category filter All / Work / Materials / Supervision
- Source-reviewed instruction, recorded source date and optional source due date
- A visible explanation that **resolution status is not currently proven**
- Contextual link to that site's separate Daily Progress page
- Clear no-results and unavailable-source states; no raw provider messages, private evidence, employee/payroll or financial fields

The underlying projection is unchanged: the existing 5 original Google Sheets, original approved public project controls, source hash/version checks and read-only WIF double-read. No new Google Sheet is fabricated or mutated.
