# v3.0.0 — Field Navigation Repair and Four-Lane Source Extraction Desk

**Release date:** 14 November 2026 (Asia/Kathmandu). **Module:** `FabinGurung/jp-site-operations`.

## Mobile field usability
- Replace the wide, repeatedly clipped desktop navigation with a compact sticky **Menu** control on phones; three primary routes (Project Map, Notifications, Extraction). Older Daily Progress and Sources & History retain their existing URLs behind the phone Menu and Extraction reference section.
- Fix original 320–430px phone viewport overflow from long provenance enums / min-content grid widths. Format source dates in plain language, hide historical-Git-index noise, and keep exact source facts available via the versioned JSON.
- Use 16px or larger font on iOS input/select fields to avoid Safari focus auto-zoom; at least 46–48px phone menu targets. Do not replace field coordinates/status permissions or modify map source data.

## Four-lane extraction and Run 01
- `extraction.html` is a source-backed four-lane desk: (1) chat intake by provider IDs, (2) original evidence/version/SHA-256, (3) normalized site instruction/work review, (4) public publication + source reconciliation.
- `extraction-status.json` is generated **inside the same seven original Google Sheets authenticated, read-only double-read** that generates `operations.json`; only public aggregates, dates, source statuses and quality boundaries. No raw chat texts, private source IDs, payroll, original evidence bytes or financial fields.
- Actual original source observations on 14 Nov: 30 project identities / 29 public, 30 publication settings, 1 versioned message source, 22 reviewed published notices, 3 unverified work reports, 9 organization IDs, 34 publishing directory entries. Latest reported work 9 Oct; latest reviewed source 26 Oct. No source row was altered, and **no new provider message was ingested** in this release.
- [Run 01 handoff and next batch](../operations/EXTRACTION_WORKFLOW_RUN01.md): one bounded source folder or channel, original file byte/hash verification, at most three reviewed new notice proposals, then PRE/POST Sheet snapshots and same-ID source edits only if verified facts are available. Slack, Discord and Telegram direct collectors remain separately blocked.
- Existing `v2.9.0` is the **rollback/archival milestone**, with predecessor UI and old report/source routes retained. This release does not create a duplicate Google Sheet or move existing Drive files.
