# v3.0.0 — Field Extraction Desk and iOS Navigation Repair

**Release date:** 14 November 2026 (NPT). **Repository:** `FabinGurung/jp-site-operations`.

## Scope
Mobile Sources & History currently renders a long technical status token beyond the viewport and exposes a clipped, horizontally scrolling top navigation. This release removes that obstruction with a compact sticky, keyboard- and touch-accessible mobile menu across Map, Daily Progress and Sources & History; long source status strings wrap inside responsive cards and human-readable labels replace internal constants.

The new same-site `/extraction.html` is a **four-lane public-safe source checkpoint** with source inventory, reviewed notifications, historical reported work and prospective material/plant/crew demand. `/extraction-status.json` is generated every successful read-only Google Sheets publication directly from the seven registered original Sheet/tab inputs. It counts rows, checks source pointer/unique-key and ID links and records readback/source dates separately; no raw Slack, Discord, Telegram, attachments, payment or staff data are emitted.
