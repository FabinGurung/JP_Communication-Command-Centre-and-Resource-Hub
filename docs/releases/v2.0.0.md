# JP AEC Operations Hub v2.0.0

Release date: 2026-10-06

## Release scope

v2.0.0 promotes the repository from the v1.1.0 data-driven project-map baseline into the broader **JP AEC Operations Hub**.

It includes:

- canonical project-master data in `projects.csv`;
- Daily Ops current state, append-only event history and project-resource relationships;
- Project Map, Site Operations and per-project operations pages;
- permission-gated Google Drive engineering-resource links;
- the owner/manager `/workspace/` with dynamic project status, System Health, edit routing and specialist-module ownership;
- the 1/3/7/15-page `/guide/` framework with 15 public-safe SVG operational illustrations and print support;
- normalized module ownership for Scheduling, Cost, Structural, CAD, R&D and Study Hub;
- stale-repository-name enforcement and current schema identifiers;
- GitHub Actions validation with **main as the sole GitHub Pages production deployment owner**.

## Canonical data/storage boundary

The production Pages application remains file-first. CSV/JSON/JSONL own current/public structured values and history; Google Drive owns source/evidence file bytes and permissions; Sheets/Slack are controlled human input/projection surfaces; the PostgreSQL schema is a relationship/constraint contract. A live Neon/PostgreSQL server is not required for this release.

## Release gates

The release may be promoted to `main` only when:

1. machine-data and route validation passes;
2. Phase-5 internal-link/accessibility/print-contract QA passes;
3. `main` is a fast-forward target with no divergent commits;
4. the production `main` Actions run succeeds;
5. the exact deployed Pages artifact passes desktop/mobile runtime and guide print/PDF QA;
6. Root-11 Local/Main A9 registration and provider readback close cleanly.

## Rollback

A pre-Phase-5 working snapshot and a pre-main-promotion snapshot are retained as governed rollback points.

## Non-goals

- no authenticated admin/write-back backend;
- no live PostgreSQL/Neon dependency;
- no migration of private Drive file bytes into the public repository;
- no transfer of specialist scheduling/cost/structural/CAD ownership into Daily Ops.
