# v2.9.0 — Map-first Field Workspace & Seven-Workbook Source Reconciliation

**Date:** 13 November 2026 (NPT). **Scope:** JP Site Operations only; source-workbook facts unchanged.

## User experience
- Simplify the home screen: site map first, one on-demand Notification Center below it only after selecting a site. Source metrics and developer-oriented panels are removed from the default home layout; Daily Progress and Sources & History remain separate internal pages.
- Collapse advanced five-layer controls by default. Retain working Sites/Work/Materials/Manpower/Notifications layers with explicit uncertainty for unconnected demand, but do not make them the primary field-workflow.
- Desktop site navigator stays sticky within the viewport and scrolls independently of the map; mobile navigation minimizes unused directory content. On narrow screens, source-approved status chips are touch-friendly.
- 48-pixel map-marker touch target. Clicking a marker opens source-reviewed site notifications **without removing other pins or resetting the camera**. Explicit Back to all sites, blank-map tap and Escape dismiss; panning/zooming does not accidentally discard a selected site.
- Other evidence boundaries and source counts remain in the separate Sources & History view. No worker/payroll, project-specific private source references or financial records are introduced.
