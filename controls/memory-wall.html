Poster 01 · Non-negotiable

Keep the working link unchanged

One stable URL.
Every edit, a new revision.

Maintain the exact GitHub-backed Colab file path. Do not make the operator copy/paste into a different notebook or switch links just because the code changed.

SAME GITHUB PATHNO BLIND OVERWRITE
Poster 02 · Version discipline

Date first. Number everything.

YYYYMMDD-NNN

Use Nepal creation date; increase the three-digit ordinal for every change—including one typo, markdown comment, bugfix, or cell metadata edit. Never reuse old numbers.

Current working revision: Loading registry…. Past revisions are archived by source-creation date. Archive creation time is separately recorded.
Poster 03 · Immutable edit sequence

No change without a PRE snapshot

1. READGet current GitHub SHA and notebook bytes
2. PREDuplicate into a new numbered archive
3. EDITUpdate the original working path
4. POSTValidate, compare and provider-readback
5. REGISTERAppend revision to JSON manifest & publish

Preserve: Git commits, prior notebook bytes, archive links, revision dates and machine manifest. A Github-backed Colab URL is not a Google Drive `/drive/` ID—do not claim a Drive-native same-ID copy.

Poster 04 · Daily intake

Source → Drive → GitHub → Website → Reply

  1. Run the bounded two-channel Discord Colab before A9-CWO; read frozen run receipt.
  2. Read governed Slack channels, threads and both company rollups.
  3. Preserve original messages and media bytes in existing A9 Drive archives.
  4. Reconcile source-grounded project facts into versioned GitHub JSON, JSONL and CSV.
  5. Validate/deploy the derived website, then send authorized Slack summaries with receipt IDs.

Discord image uploaded ≠ site work accepted as DONE.

Poster 05 · Runtime rule

A running cell is not proof of completion

If Colab shows only Google transport warnings, inspect its current 20-second heartbeat and its last named operation. Do not assume messages were extracted or images uploaded until the final receipt is read back.

Look for: FINAL RECEIPT and PASS/PARTIAL; counts for each channel, attachment failures, Drive receipt ID and handoff ID. If no final receipt, report incomplete.

Never paste Discord bot tokens into chat, repo files, PDFs or notebook output. Use Colab Secrets.
